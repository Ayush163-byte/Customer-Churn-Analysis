# Customer Churn Analysis

## Project Overview

This project analyzes customer churn data to understand customer behavior and identify factors associated with customer churn.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains information about 7,043 customers, including:

- Churn status
- Contract type
- Internet service
- Payment method
- Monthly charges
- Customer tenure

## Exploratory Data Analysis

The project includes analysis of:

- Churn distribution
- Contract Type vs Churn
- Payment Method vs Churn
- Internet Service vs Churn
- Monthly Charges vs Churn
- Tenure vs Churn
- Overall Churn Rate

## Key Results

- Total Customers: 7,043
- Churned Customers: 1,869
- Retained Customers: 5,174
- Churn Rate: 26.54%

## Business Insights

- Month-to-month contract customers show higher churn compared with longer-term contracts.
- Churn varies across different internet service categories.
- Payment methods show differences in customer churn.
- Monthly charges differ between churned and retained customers.
- Customer tenure provides useful information about churn behavior.

## Conclusion

The analysis shows that customer churn is an important business problem, with 26.54% of customers having churned.

The analysis of contract type, internet service, payment method, monthly charges, and tenure provides useful insights into customer churn behavior. These insights can help businesses identify customer groups that may require better customer retention strategies.
